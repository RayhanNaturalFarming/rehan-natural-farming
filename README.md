# Rehan Natural Farming — GitHub Pages

A simple, responsive website for Rehan Natural Farming.

## Publish for free with GitHub Pages

1. Create/sign in to your GitHub account.
2. Create a new **public** repository, for example `rehan-natural-farming`.
3. Upload `index.html`, `style.css`, and `script.js` from this folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide your free `github.io` website address.

## Before publishing

Replace:
- `+91 XXXXXXXXXX`
- `your-email@example.com`
- `Your Farm Location, Telangana, India`
- Sample product names/details
- The WhatsApp link `https://wa.me/91XXXXXXXXXX`

You can also replace the sample Unsplash hero image with your own farm photo.
